🔄 工作流逐步解析

1

用户输入

用户在命令行输入消息，如「北京天气怎么样」「明天从上海到北京的高铁」「你好」

⬇️
2

意图分析 LLM

analyze_intent 节点使用 LLM 分析用户消息，判断意图（weather / ticket / chat）并提取参数（城市名、出发地、目的地、日期）。
当 LLM 不可用时，自动降级为关键词匹配（匹配城市列表 + 天气/车票关键词）。


示例输出：{"intent": "weather", "city": "北京"}
⬇️
3

条件分支 ⚡

chat → 直接跳到 响应生成
weather / ticket → 进入 工具路由

⬇️
4

工具路由 纯逻辑

route_tool 节点检查参数完整性：

  • 天气查询需要 city
  • 车票查询需要 fromStation + toStation + date
  • 参数缺失 → 返回友好提示，直接进入响应生成
⬇️
5

工具执行 MCP内置

execute_tool 节点根据路由结果调用对应工具：

  • 天气 → 内置工具，直接 HTTP 调用 中国天气网 API（无需 Key）
  • 车票 → MCP 协议，通过 stdio JSON-RPC 调用 mcp-server-12306 服务器
⬇️
6

响应生成 LLM

generate_response 节点使用 LLM 将工具返回的原始数据格式化为友好的中文回复（含表情符号、表格、出行建议等）。
LLM 失败时降级显示原始 JSON 数据。

⬇️
7

输出

用户看到格式化的友好回复 ✨

🔍 节点详情

🧠 analyze_intent

LLM降级

类型: LLM 调用 + 关键词降级
输入: 用户消息文本
输出: intent + extracted_params
降级: 匹配城市列表/车票/天气关键词
工具: 无

🔀 route_tool

纯逻辑

类型: 同步函数
输入: intent + extracted_params
输出: mcp_server + tool_name + tool_args
功能: 校验参数完整性，准备工具调用
工具: 无

⚡ execute_tool

MCP内置

类型: 异步工具调用
输入: mcp_server + tool_name + tool_args
输出: mcp_result (原始数据)
功能: 调用 MCP 服务器或内置工具
工具: weather / 12306

💬 generate_response

LLM

类型: LLM 调用 + 模板降级
输入: intent + mcp_result / error
输出: final_response (友好文本)
降级: 展示原始 JSON 数据
工具: 无

📦 AgentState (TypedDict)

LangGraph 在节点间传递的状态对象，定义于 agent/state.py

class AgentState(TypedDict):
    # 对话历史（自动追加）
    messages: Annotated[Sequence[BaseMessage], add_messages]

    # 意图分析结果
    intent: str                    # weather | ticket | chat
    extracted_params: dict          # {city, from_city, to_city, date}

    # 工具路由结果
    mcp_server: str                # 目标服务器名
    tool_name: str                 # 要调用的工具名
    tool_args: dict                 # 工具参数

    # 执行结果与最终输出
    mcp_result: dict               # MCP 工具返回的原始数据
    final_response: str            # 最终回复文本
    error: str                     # 错误信息

🔧 MCP 工具注册表

系统启动时自动发现并注册所有工具

工具名来源类型说明
get_weather weather 内置 通过中国天气网 API 查询城市天气（无需 Key）
get-current-date 12306 MCP 获取当前日期（用于相对日期计算）
get-station-code-of-citys 12306 MCP 通过城市名查询车站代码
get-station-code-by-names 12306 MCP 通过车站名查询车站代码
get-tickets 12306 MCP 查询 12306 余票信息（主功能）
get-interline-tickets 12306 MCP 查询中转车票
get-train-route-stations 12306 MCP 查询列车途经站点

📡 MCP 通信协议 (JSON-RPC 2.0 over stdio)

👈 客户端 → 服务器

// 1. 初始化握手
{"jsonrpc": "2.0", "id": 1,
 "method": "initialize",
 "params": {"protocolVersion": "2024-11-05",
            "clientInfo": {"name": "travel-agent"}}}

// 2. 列出工具
{"jsonrpc": "2.0", "id": 2,
 "method": "tools/list"}

// 3. 调用工具
{"jsonrpc": "2.0", "id": 3,
 "method": "tools/call",
 "params": {"name": "get-tickets",
            "arguments": {"date": "2026-06-07",
                           "fromStation": "北京",
                           "toStation": "上海"}}}

👉 服务器 → 客户端

// 1. 初始化响应
{"jsonrpc": "2.0", "id": 1,
 "result": {"protocolVersion": "2024-11-05",
            "serverInfo": {"name": "mcp-server-12306"}}}

// 2. 工具列表
{"jsonrpc": "2.0", "id": 2,
 "result": {"tools": [
   {"name": "get-tickets",
    "inputSchema": {"properties": {
      "date": {"type": "string"},
      "fromStation": {"type": "string"},
      "toStation": {"type": "string"}}}}]}}

// 3. 工具结果
{"jsonrpc": "2.0", "id": 3,
 "result": {"content": [
   {"type": "text",
    "text": "车次 G2, 09:00-13:30..."}]}}
